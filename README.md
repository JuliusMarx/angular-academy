# Angular Academy

Eine interaktive Lernplattform für Angular, ähnlich wie W3Schools: kurze Lektionen, Codebeispiele zum Ausprobieren direkt im Browser und Übungen mit sofortigem Feedback.

## Status

🚧 In Planung

## Ideen

- Lektionen von den Grundlagen bis zu fortgeschrittenen Themen (Komponenten, Templates, Signals, Routing, Forms, HttpClient, …)
- Live-Code-Editor mit Vorschau („Try it yourself“)
- Übungen und Quizze mit automatischer Auswertung
- Lernfortschritt speichern
